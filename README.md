# Iris Classifier

A quick and easy Python script that trains and evaluates a decision tree classifier on the classic Iris dataset, then displays a confusion matrix.

## Requirements

- scikit-learn
- matplotlib

## Usage

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the script:
   ```
   python iris_classifier.py
   ```

The script will print the test accuracy and display a confusion matrix plot.
